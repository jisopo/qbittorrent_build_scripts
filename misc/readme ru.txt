Это дополнительный скрипт, который для самой работы не требуется но может быть полезен.

Что делает:
Скрипт сравнивает 2 папки и на выходе получаем .patch файл.
Очень удобно сравнить пропатченные файлы qt с оригинальными для получения патча с измененями.

Переменные:
folder_original - папка с исходниками qt без каких-либо правок
folder_patched - пропатченные исходники из репозитория <название> (ссылка)

patch_file_name - полный путь до файла с патчем который будет создан после отрабки скрипта.

Как применить патч:
git apply file.patch

Примеры можно посмотреть в scripts/patch_qt6.8.3.bat

Окружение:
Было проверено на:
windows 8.1
python 3.10.7
git 2.31.1
