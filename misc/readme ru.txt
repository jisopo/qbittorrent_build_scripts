Это дополнительный скрипт, который для самой работы не требуется, но может быть полезен.

Что делает:
Скрипт сравнивает 2 папки и на выходе получаем один .patch файл.
Очень удобно сравнить пропатченные файлы qt с оригинальными для получения патча с измененями, который потом можно наложить одной командой.

Переменные:
base_path - папка с вложенными папками, с оригинальным и пропатченными исходниками
folder_original - название папки которая находится в base_path с исходниками qt без каких-либо правок
folder_patched - пропатченные исходники которые находятся в папке base_path

patch_file_name - название патч файла который будет создан в base_path после отрабки скрипта.

Как применить патч:
git apply file.patch

В штатных случая этого достаточно, но в случае с qt используются следующие параметры:
git apply --whitespace=nowarn --unsafe-paths file.patch

Для наложения патчей так же можно использовать графический интерфейс программмы tortoise git:
Открыть .patch file -> File -> Apply Patch -> Select 'qt-everywhere-src-6.10.0' extracted folder -> Patch all items

Примеры можно посмотреть в scripts/patch_qt_6.9.3.bat

Было проверено на:
windows 8.1
python 3.10.7
git 2.31.1
